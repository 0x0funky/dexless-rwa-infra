## 營運注意事項

**Keeper 必須持續運行** —— 它是鏈上數據的來源,停了養熟也停。
需放在長期開機的機器上,本機關機即中斷。

```bash
npm run keeper:mainnet
```

**餘額監控**(15 分鐘一輪可撐約 44 天,足以到 9/30):

```bash
ENV_FILE=.env.mainnet npm run wallets:status
```

報價者餘額不足時:

```bash
npm run wallets:fund:mainnet
```

**市場養熟**:主網為 1 小時 + 12 輪驗證。15 分鐘一輪 → 12 輪需 3 小時。
Demo 前務必提前提案,現場等不了。
