## 3. 映射結構

**採 1:1 完全擔保，且由合約強制執行，非政策承諾。**

```
1 dXAU  ⟷  1 金衡盎司託管黃金
```

實作機制（`RWAToken.mint()`）：

```solidity
uint256 attested  = assetRegistry.attestedUnits(assetId);
uint256 newSupply = totalSupply() + amount;
if (newSupply > attested) revert ExceedsAttestedReserves(newSupply, attested);
```

- 鑄造量**永遠不可能**超過託管方最新申報的儲備量 —— 超額鑄造在合約層直接 revert
- 託管申報逾 35 天未更新 → `isMintable()` 回傳 false → 鑄造全面停止
- 任何人可隨時呼叫 `backingRatioBps()` 查詢即時擔保率（10000 = 剛好 100%）
- 贖回即銷毀，鏈上供給與鏈下儲備由設計本身收斂，無需信任發行方

> 本專案**不採用**部分準備或超額槓桿結構。

## 4. 數據上鏈方式

| 數據 | 上鏈方式 | 頻率 | 合約方法 |
| --- | --- | --- | --- |
| 託管儲備量 | 託管方簽章報告 → 鏈上申報 | 【待填】每月 / 每週 | `attestCustody()` |
| 儲備報告全文 | IPFS，鏈上存 CID + keccak256 摘要 | 同上 | `attestCustody(proofURI)` |
| 資產市價 | 多來源 API → 鏈上五重驗證 | 每 5 分鐘 | `submitQuote()` → `validate()` |
| 法律文件 | IPFS，鏈上存 CID + 摘要 | 異動時 | `registerAsset(legalDocURI)` |
| KYC 認證 | 持牌機構 → 記錄雜湊上鏈（個資不上鏈） | 逐一申請時 | `attest()` |

**價格來源組成**（至少 3 個獨立來源、橫跨 ≥ 2 種類別）：

| 來源 | 類別 | 說明 |
| --- | --- | --- |
| Binance PAXG/USDT | `CEX` | 交易所頂部訂單簿含掛單量 |
| OKX PAXG/USDT | `CEX` | 獨立交易所，避免單一場所停機即斷線 |
| 【待填】造市商 RFQ | `MM_QUOTE` | 【待填 —— 是否已與造市商簽約？】 |
| 【待填】JEPUN NAV | `NAV` | 【待填 —— 基金行政管理人淨值，適用基金份額型標的】 |

所有驗證結果（含每一筆被拒絕的來源與理由）皆以事件寫入鏈上，可完整回溯。

## 5. 業務可用性與價值流轉邏輯

完整生命週期，每一步皆為鏈上交易（tx hash 見 [`onchain-flow.md`](./onchain-flow.md)）：

```
資產登記 → 儲備申報 → 價格驗證 → 投資人 KYC → 1:1 鑄造
    → 市場提案 → 養熟驗證 → 市場啟用 → 持有人交易
    → 收益分配 → 贖回銷毀 → 託管儲備同步減少
```

**價值流轉**
1. **一級發行**：投資人完成 KYC 與鏈下申購 → 託管方收妥實物並申報 → 鑄造代幣
2. **二級流通**：持有人之間轉讓，雙方皆須通過 `ComplianceRegistry` 檢查
3. **衍生市場**：`MarketFactory` 開立永續合約市場，接入 Orderly 共享流動性，
   價格由 `PriceValidationEngine` 供應
4. **收益分配**：標的孳息或市場手續費 → `FeeDistributor` 按持倉快照分配，
   完整分配表上傳 IPFS，任何人可重算 Merkle Root 驗證分配未經竄改
5. **贖回退出**：銷毀代幣 → 鏈下交割 → 下期儲備申報反映減少

**業務可用性**：本資產並非僅供展示 —— 它是 DEXless 永續市場的標的資產，
且其定價基礎設施對任何第三方協議開放呼叫。
